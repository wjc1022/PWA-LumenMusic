# PrivateKara

[English](./README.md) | 简体中文

**自备媒体的卡拉 OK 渐进式 Web 应用（Bring Your Own Media Karaoke PWA）**

PrivateKara 是一款优先面向手机的渐进式 Web 应用，主要用于实体 KTV：当场所曲库里没有你想唱的歌时，使用自己准备的资源演唱。提前准备音频、音乐视频（MV）、伴奏和同步歌词，再通过手机管理和播放。主要设想是将 iPhone 屏幕镜像到场所的显示设备，并通过现场可用的设备输出声音。

目前这是一个个人项目，未来可能向公众开放。PrivateKara 不提供、搜索、下载或生成音乐、视频、伴奏或歌词。媒体由用户自行提供，用户需自行确保拥有相应使用权。

## 当前功能

以下能力已在代码中实现，并经源码核对。这里说明的是实现情况，不代表已通过真实设备验收；验证范围见下文。

- **本地媒体库：**通过文件选择器或桌面拖放导入音频和视频；在可读取时提取音频元数据及内嵌封面。媒体、歌词、歌单、收藏和设置保存在本地 IndexedDB 中，无需账号或应用后端。
- **播放与整理：**支持媒体库搜索和排序、歌单管理及顺序调整、收藏、播放队列、上一首／下一首、进度定位、随机播放，以及关闭循环／列表循环／单曲循环。迷你播放器与展开播放器共用播放状态；主动选歌会展开播放器，收起后仍可在前台继续播放。
- **歌词：**在音乐库的歌曲资源控件中，为每首歌导入或替换一份原始 LRC／纯文本歌词文件。与媒体一起选择的同名 `.lrc` 文件可自动关联。定时歌词支持滚动和当前行高亮；Enhanced LRC 的 `<mm:ss.xxx>` 片段已支持当前字词及已唱字词高亮。纯文本仅静态显示，不进行时间同步。歌词支持任意语言及混合语言；不提供歌词编辑器或翻译服务。
- **音频原唱／伴奏切换：**在音乐库中为音频条目关联另行准备的伴奏文件，然后切换原唱与伴奏。引擎会尝试保留播放位置及播放／暂停状态，但不保证无缝切换。视频／MV 的伴奏切换尚未实现。
- **视频显示：**支持页面内播放、横屏歌词侧栏、字幕开关、响应式控件，以及播放时自动隐藏控件。竖屏视频隐藏歌词区域。全屏请求和方向锁定提供页面内铺满／旋转的回退方案；页面内铺满无法隐藏浏览器工具栏等界面。
- **前台播放：**在支持时申请屏幕常亮（Screen Wake Lock）。页面进入后台会暂停，返回前台后仍保持暂停，需手动点击播放。
- **备份与离线支持：**支持 JSON 媒体库备份／恢复，以及可选择内容的 Lumen Music Package（`.lmp`）导入／导出，包含媒体、伴奏、歌词和媒体库记录。首次成功加载后，Service Worker 缓存应用壳以供离线使用；导入的媒体保存在浏览器本地存储中。
- **偏好与诊断：**提供英语、简体中文和波斯语界面，深色／浅色／跟随系统主题、播放器按钮显示设置、睡眠定时器、更新检查，以及设置页中的本地资源诊断。

本地已有最近播放和播放次数，但它们只是基础的选歌记录，不能视为有明确统计意义的完整演唱记录。

## 运行方式

应用使用原生 HTML、CSS 和 JavaScript ES 模块，无 npm 依赖，也无需构建。

仓库：[wjc1022/PrivateKara](https://github.com/wjc1022/PrivateKara)。已完成的检查和待验证的部署事项见[重命名验证记录](./docs/REPOSITORY_RENAME.md)。

克隆并进入仓库，再使用 Python 3 启动服务：

```sh
git clone https://github.com/wjc1022/PrivateKara.git
cd PrivateKara
```

```sh
python -m http.server 8080
```

打开 `http://localhost:8080`。手机访问和 PWA 测试请使用静态 HTTPS 站点；手机上的 `localhost` 指向手机自身。不支持通过 `file://` 直接打开 `index.html`。Service Worker 等要求安全上下文的 API 需要 HTTPS 或受信任的 localhost 来源。

在 iPhone 上，用 Safari 打开 HTTPS 站点，通过**分享 → 添加到主屏幕**尝试安装后的 PWA。应用文案和 PWA 安装名称使用 **PrivateKara**。

## 在 KTV 中使用

1. 到店前准备可播放的媒体及对应歌词。如果文件位于“文件”应用中的云端位置，请先确保已下载到本地再选择；这属于文件导入，并非集成的网盘流媒体播放。
2. 在首页或音乐库点击 **Import songs（导入歌曲）**。若需自动关联歌词，请同时选择媒体和同名 `.lrc` 文件；也可在音乐库中打开对应歌曲的资源控件，添加／替换歌词，或为音频条目关联伴奏。
3. 选歌或从歌单开始播放，在展开播放器中查看歌词和操作播放；浏览媒体库时可使用迷你播放器。
4. 通过 iPhone 系统控件启动屏幕镜像，使用现场可用的显示和音频连接。镜像是预期使用方式，不是由应用管理的第二屏连接；正式使用前请测试实际设备组合。
5. 在设置中导出 JSON 备份或 `.lmp` 包，并在浏览器之外保留原始文件。

## 已知限制与验证状态

- **iOS Safari 和安装后 PWA 的可靠性尚未得到充分验证。**项目记录包含桌面自动化检查，但真实 iPhone 验收尚未完成。文件选择（包括 LRC／TXT 和云端文件）、重启后的存储、实际声音输出、持续播放、屏幕常亮、触摸交互、全屏／方向及场所镜像仍需真机验证。桌面检查通过不等于设备兼容性保证。
- iPhone PWA 重启后媒体无法读取、播放停滞，以及实际原唱／伴奏文件对的定位异常，仍是未解决的设备问题。设置中的诊断可检查存储资源和媒体加载情况；成功加载元数据不代表一定能正常播放。
- 文件能够导入，不保证浏览器支持其编码。iPhone 原生视频全屏不会包含自定义 HTML 歌词侧栏；全屏／方向 API 和屏幕常亮可能不可用或被系统拒绝。
- 应用面向前台播放，后台和锁屏播放不属于可靠支持的使用方式；屏幕常亮无法覆盖系统拒绝或用户手动锁屏。
- 浏览器存储不能替代长期备份：容量限制、清除网站数据、存储回收，以及设备／浏览器故障都可能导致本地资源不可用。目前没有云同步，也不会从原始文件自动恢复。
- **升级兼容性：**当前 `lumen-db` 升级到版本 2 时会清空旧应用数据库，需要重新导入。当前 JSON 备份使用 `formatVersion: 3`，`.lmp` 包使用 `packageFormatVersion: 3`；旧版本备份／包会被拒绝导入。原始文件和已下载的备份独立于应用数据库。

## 后续开发

以下为计划方向，不代表已实现的新能力：

- 改进现有 Enhanced LRC 逐字高亮，并在真实设备上验证时序、可读性、进度定位和原唱／伴奏切换。基础逐字时间标签解析和高亮已经存在。
- 为视频／MV 增加伴奏切换，并保持视频、音频和歌词同步。
- 增加个人网盘媒体导入与流式播放，明确授权和离线行为。
- 定义适合卡拉 OK 场景、具有实际意义的播放历史和计数规则，并增加个人记录的云端持久化。现有本地最近播放／计数和手动备份尚不提供这些能力。
